# Beulendoktor Damiko – Autolackierung, Smart Repair & Dellentechnik

Moderne Webpräsenz für **Beulendoktor Damiko (Damiko Dellentechnik)** in Frankfurt am Main auf Basis des einheitlichen Projekt-Stacks (**React 19 + Vite 8 + React Router 7 + CSS Modules + Vercel Serverless Functions + Resend + Firebase Firestore**).

## Skripte

- `npm.cmd run dev` – Lokaler Entwicklungsserver
- `npm.cmd run lint` – ESLint-Prüfung
- `npm.cmd run build` – Produktions-Build inkl. SEO-Meta-Prerendering (`scripts/prerender-meta.mjs`)
- `npm.cmd run preview` – Vorschau des Produktions-Builds

Weitere Details in [tech_and_style.md](./tech_and_style.md) und [deployment_guide.md](./deployment_guide.md).
